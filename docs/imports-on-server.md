# Папка экспорта Telegram на сервере (`data/imports/`)

Чтобы при импорте сохранялись **фото и видео**, на сервере нужна не только `result.json`, а **вся папка** экспорта из Telegram Desktop.

Если залить только JSON через браузер — текст задач импортируется, а файлы **некуда взять** (в JSON лишь пути вроде `video_files/…`).

## Что экспортировать

В Telegram Desktop:

1. Чат «Идеи для заданий…» → ⋮ → Export chat history  
2. Включить **Photos**, **Video messages**, **Video files**, **Files**  
3. Формат JSON  

Получится папка примерно такая:

```
ChatExport_2026-07-27/
  result.json
  photos/
  video_files/
  files/
  stickers/   (не обязательно)
```

## Как положить на сервер

Антон (или у кого есть SSH/SFTP), **один раз после нового экспорта**:

```bash
# на сервере
cd /path/to/tyuf-tyue-zadachi
mkdir -p data/imports
# скопировать папку ChatExport_… целиком в data/imports/
# например: data/imports/ChatExport_2026-07-27/
```

Способы: `scp`, `rsync`, SFTP (FileZilla / Cyberduck).

Проверка:

```bash
ls data/imports/*/result.json
ls data/imports/*/video_files | head
```

После `git pull` + рестарта приложения на странице **Импорт** в выпадающем списке появится эта папка.

## Как импортировать на сайте

1. Импорт → выбрать папку в «Папка на сервере»  
2. Разобрать → дождаться прогресса  
3. Проверить превью видео (должен быть плеер, не надпись «видео»)  
4. Сохранить обработанные  

## Если превью «видео» без плеера

Значит `export_root` пустой: разобрали только JSON без папки. Залейте экспорт в `data/imports/` и разберите снова.
