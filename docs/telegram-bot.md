# Бот задач ТЮФ/ТЮЕ

Бот работает **в две стороны**.

## 1. С сайта → в чат идей

Добавили задачу на сайте → в чат идей приходит сообщение с названием, условием, тегами, ссылкой и файлами (если есть).

## 2. Из чата идей → на сайт

Написали идею **в чате идей** в таком виде:

```
Идея №12
Название
Условие…
Теги: ТЮФ, ТЮЕ
https://ссылка-если-есть
```

Теги — по-русски, можно несколько через запятую. Примеры:

- `Теги: ТЮФ, ТЮЕ`
- `Теги: Капитанка`
- `Теги: ТЮФ, SF4`
- или хештеги в тексте: `#ТЮФ #ТЮЕ`

Если строку с тегами не указать, по умолчанию ставятся **ТЮФ** и **ТЮЕ** (для капитанки — если в тексте есть «КК» / «конкурс капитанов»).

Можно приложить фото/видео к тому же сообщению.

Комментарий к уже существующей идее:

```
К идее №12
Текст комментария…
```

Дальше:
1. Один раз откройте бота в личке и нажмите **Start** (`/start`) — иначе превью не придёт.
2. Бот пришлёт **превью в личку** (в общий чат не спамит).
3. Нажмите **«Сохранить»** или **«Отмена»**.

После «Сохранить» задача/комментарий появляются на сайте; о новой задаче чат идей получит обычное уведомление.

## Текст для чата идей (можно скопировать)

```
Уважаемые коллеги!

Мы подключили бота к учёту задач ТЮФ/ТЮЕ — чтобы идеи из чата попадали на сайт, а новые задачи с сайта были видны здесь.

Сайт: https://problems.folomin.com/
Бот: @tyuf_tyue_zadachi_bot

Сначала один раз откройте бота и нажмите Start — иначе он не сможет писать вам в личку.

Как это работает

1. С сайта → в этот чат
Если задачу добавили на сайте, сюда придёт сообщение (название, условие, теги, ссылка и т.д.).

2. Из этого чата → на сайт
Напишите идею здесь в таком формате:

Идея №12
Название
Условие…
Теги: ТЮФ, ТЮЕ

Теги можно несколько, по-русски. Примеры:
• Теги: ТЮФ, ТЮЕ
• Теги: Капитанка
• Теги: ТЮФ, SF4
• или так: #ТЮФ #ТЮЕ

Если строку «Теги: …» не указать — по умолчанию будут ТЮФ и ТЮЕ.
Можно добавить ссылку и фото/видео к тому же сообщению.

Комментарий к уже существующей идее:

К идее №12
Текст комментария…

Дальше бот пришлёт превью в личку (в чат не спамит). Там нажмите «Сохранить» или «Отмена». После сохранения задача появится на сайте.
```
