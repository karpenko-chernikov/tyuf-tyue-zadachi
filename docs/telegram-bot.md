# Бот задач ТЮФ/ТЮЕ

Бот работает **в две стороны**.

## 1. С сайта → в чат идей

Добавили задачу на сайте → в чат идей приходит сообщение с названием, условием, тегами, ссылкой и файлами (если есть).

## 2. Из чата идей → на сайт

Написали идею **в чате идей** в таком виде:

```
Идея №12
Название
Условие…
https://ссылка-если-есть
```

Можно приложить фото/видео к тому же сообщению.

Комментарий к уже существующей идее:

```
К идее №12
Текст комментария…
```

Дальше:
1. Один раз откройте бота в личке и нажмите **Start** (`/start`) — иначе превью не придёт.
2. Бот пришлёт **превью в личку** (в общий чат не спамит).
3. Нажмите **«Сохранить»** или **«Отмена»**.

После «Сохранить» задача/комментарий появляются на сайте; о новой задаче чат идей получит обычное уведомление.
