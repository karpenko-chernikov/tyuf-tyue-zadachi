# Обновление сервера (для Антона)

У тебя уже есть рабочий сайт и своя БД. Нужно подтянуть новый код с git и донастроить Telegram. Базу **не затирай** и **не подменяй** чужим `zadachi.db`.

## 1. Обновить код

На сервере, в каталоге проекта:

```bash
cd /path/to/tyuf-tyue-zadachi   # свой путь
git pull
```

Если используешь venv:

```bash
.venv/bin/pip install -r requirements.txt
```

(появился пакет `httpx` — без него бот не заработает.)

## 2. Дописать `.env`

Файл `.env` на сервере **уже свой** — его git не перезапишет. Открой и добавь / проверь:

```env
TELEGRAM_BOT_TOKEN=…          # токен от @BotFather (спроси у Никиты, если нет)
TELEGRAM_CHAT_ID=-4781372763  # чат «Идеи для заданий на ТЮФ и ТЮЕ»
APP_BASE_URL=https://problems.folomin.com
TELEGRAM_MONTHLY_DAY=1

# Почта для бэкапа (TXT + при возможности gzip БД). Пароль приложения Gmail:
SMTP_HOST=smtp.gmail.com
SMTP_PORT=587
SMTP_USER=…@gmail.com
SMTP_PASSWORD=…               # App Password, не обычный пароль
SMTP_FROM=…@gmail.com         # можно тот же, что USER
```

`SECRET_KEY`, `DATABASE_URL`, пароли `PASS_*` — **не трогай**, если сайт уже работает.

`APP_BASE_URL` — без слэша в конце. От этого зависят ссылки в уведомлениях бота.

День выгрузки и список почт дальше правятся в **Настройки** на сайте (`data/backup_config.json`). Если БД больше ~18 МБ, письмо уйдёт с TXT и пометкой скачать БД кнопкой «Скачать БД».

## 3. Перезапустить приложение

Обновление страницы в браузере **недостаточно**. Нужен рестарт процесса.

Примеры:

```bash
# если через run.sh — Ctrl+C в том терминале, потом:
./run.sh
```

или перезапуск docker-контейнера / systemd-сервиса — как у вас принято.

После старта в логах должно быть что-то вроде `Application startup complete` и (если токен задан) старт inbox-poller.

### Nginx / reverse proxy (видео, импорт JSON)

Лимит загрузки в приложении — **100 МБ** на вложения задач, до **500 МБ** на `result.json` импорта. Если перед uvicorn стоит nginx:

```nginx
client_max_body_size 500M;
proxy_read_timeout 300s;
proxy_send_timeout 300s;
```

Иначе большие файлы отвалятся с 413, а долгий импорт/загрузка — с 504 у Cloudflare. После правки: `sudo nginx -t && sudo systemctl reload nginx`.

## 4. Один раз настроить бота в Telegram

1. @BotFather → бот → **/setprivacy** → **Disable**  
   (иначе бот в группе не видит обычные сообщения, только команды.)
2. Бот уже должен быть участником чата идей.
3. Каждый, кто будет подтверждать идеи (хотя бы ты и авторы идей), открывает бота и жмёт **Start** (`/start`).

## 5. Быстрая проверка

1. Сайт открывается: https://problems.folomin.com/  
2. Проверка процесса: `curl -fsS https://problems.folomin.com/health` → должно ответить `ok`
3. Настройки → блок Telegram → «Тестовое сообщение» → должно прийти в чат идей.  
4. В чат идей написать тестовую идею:

```
Идея №999001
Проверка после обновления
Условие: тест Антона
```

5. Автору в **личку** с ботом должно прийти превью → «Сохранить».  
6. Задача появляется на сайте; в чат идей уходит обычное уведомление о новой задаче.
7. (По желанию) Импорт: страница «Импорт» → «Разобрать» показывает прогресс («Разбираем…»), сайт при этом остаётся открываемым.

## Чего не делать

- Не копировать поверх локальную БД Никиты — у тебя свои данные на сервере.  
- Не коммитить `.env` в git.  
- Не ждать, что `git pull` сам перезапустит сервер.

## Если что-то не так

| Симптом | Что проверить |
|--------|----------------|
| Сайт старый | не сделан `git pull` или не перезапущен процесс |
| `/health` не `ok` | процесс не поднялся; смотри логи uvicorn/systemd/docker |
| Нет уведомлений из сайта | `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`, рестарт |
| Идея в чате → тишина | Privacy Disable; у автора был `/start`; формат `Идея №…` |
| Ссылки ведут на localhost | `APP_BASE_URL=https://problems.folomin.com` |
| Ошибка про httpx | `pip install -r requirements.txt` |
| 504 / сайт «умер» на импорте | нужен свежий код (фоновый импорт) + nginx `proxy_read_timeout` / `client_max_body_size` выше |
| 413 на большом JSON/видео | nginx `client_max_body_size 500M` |

Краткая инструкция для всей команды (как пользоваться ботом): `docs/telegram-bot.md`.

Импорт с фото/видео: папка экспорта на сервере — `docs/imports-on-server.md`.
